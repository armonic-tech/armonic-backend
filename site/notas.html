v0.1.0

Primera versión

2026-07-12

El primer release usable de Armonic: una comunidad autohospedada con texto en tiempo real, voz, y el flujo completo de reclamo e invitaciones.

  • Chat de texto en tiempo real - canales de texto sobre WebSocket, con historial de los últimos mensajes. Los mensajes de otras personas llegan al instante.
  • Canales de voz - audio por WebRTC relayado por el backend (tipo SFU): varias personas en la misma sala, con reconexión automática cuando alguien entra o sale.
  • Cliente multi-instancia - app de Flutter para Android, Linux y Web. guardá y alterná entre varias instancias de Armonic, cada una con su sesión.
  • Flujo de reclamo (claim) - una instancia nueva arranca sin dueño. la primera persona que ingresa la contraseña de instancia se vuelve admin.
  • Invitaciones de un solo uso - el admin genera links de invitación (válidos 24 h) para sumar miembros. No hay registro público.
  • Moderación - el dueño puede expulsar usuarios de un canal de voz o del servidor.
  • Autohospedaje con Docker - docker compose up -d levanta la app y Postgres. el secreto de instancia se monta por fuera de la imagen.

Usamos versionado semántico.
