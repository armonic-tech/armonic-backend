Guía de uso

Empezar a usar Armonic

Esta guía tiene dos partes: primero para miembros (usar la app), después para admins (desplegar y administrar la instancia). Si alguien ya te pasó un link de invitación, podes pasar directamente a la seccion de miembros.

Miembro Usar la app

1. Instalar el cliente

Armonic tiene una app de Flutter que corre en Android, Linux y Web. Según cómo te la hayan entregado:

  • Web: abrí la URL que te pasaron en el navegador. No hace falta instalar nada.
  • Android: instalá el .apk provisto.
  • Desde el código (si compilás vos mismo): flutter pub get y luego flutter run -d chrome (o -d linux / tu dispositivo Android).

2. Agregar una instancia

Una instancia es un servidor de Armonic concreto (la comunidad de un amigo, la de tu equipo, etc.).

En la pantalla de inicio tocá “+” y pegá la URL base de la instancia (por ejemplo https://chat.miequipo.dev). La app te muestra su nombre, descripción y cantidad de miembros.

Multi-instancia: podés agregar varias instancias distintas y cambiar entre ellas desde la pantalla principal, cada una con su propia sesión guardada.

3. Crear tu cuenta

Armonic no tiene registro público. Hay exactamente dos formas de tener cuenta, y la app elige la correcta automáticamente según el estado de la instancia:

a) Con un link de invitación (lo más común)

Si te compartieron un link tipo https://…?invite=<token>, abrilo. La app te muestra a qué instancia pertenece y hasta cuándo es válido, y te pide elegir usuario y contraseña. Listo: quedás dentro como miembro.

⚠️ Advertencia: cada invitación es de un solo uso. Si el link ya fue utilizado o venció, vas a ver “esta invitación ya no es válida”. Deberas solicitarle al admin una nueva.

b) Reclamando una instancia nueva

Si la instancia todavía no tiene dueño, la app te permite reclamar el mismo: ingresás la contraseña de la instancia, después elegís usuario y contraseña, automaticamente seras el administrador.

Ver la parte de admin para el detalle.

c) Ya tenés cuenta

Si ya te habías registrado en esa instancia, simplemente iniciá sesión con tu usuario y contraseña.

5. Hablar en canales de voz

¿No se escucha? Revisá permisos de micrófono y mirá la sección de voz en la FAQ.

Admin Desplegar y administrar

El backend es un binario de Go con Postgres. La forma más simple de levantarlo es con Docker Compose.

1. Levantar el backend

Necesitás Docker. Cloná el repo del backend y, antes de arrancar, configurá el secreto de claim:

  1. Editá config.json y poné una contraseña de instancia fuerte en app.password. Esta es la contraseña que quien reclame la instancia va a tener que ingresar. 
    {
  "app": {
    "port": 8080,
    "password": "una-clave-larga-y-secreta"
  }
}

    ⚠️ El servidor no arranca si app.password está vacío o el archivo falta.

    Nunca dejes el valor por defecto change-me.

  2. Definí el JWT_SECRET (firma los tokens de sesión) en docker-compose.yml. Cambiá el change-me por un valor propio y aleatorio.
  3. Levantá todo: 
    docker compose up -d
    Esto arranca Postgres y la app; el servidor queda escuchando en el puerto 8080. En entornos productivos se recomienda tener un reverse proxy con HTTPS por delante.

2. Reclamar la instancia

Al arrancar por primera vez, la instancia existe pero no tiene dueño. Desde el cliente:

  1. Agregá la instancia por su URL. La app detecta que no está reclamada y muestra el flujo de claim.
  2. Ingresá la contraseña de instancia (la de config.json). Tenés aproximadamente 10 minutos para completar el registro antes de que el ticket expire.
  3. Elegí tu usuario y contraseña de admin. Quedás registrado, logueado y sos el dueño de la instancia.

Al reclamar se crean automáticamente un canal de texto general y uno de voz General.

3. Invitar gente

Como sos el único que puede crear cuentas, para sumar miembros generás invitaciones desde el cliente (opción de administración del servidor).

Cada invitación:

  • Produce un link tipo <url>?invite=<token> que compartís por fuera (chat, mail, etc.).
  • Es de un solo uso y vence a las 24 horas.
  • Al redimirse crea una cuenta nueva ya como miembro de tu instancia.

4. Moderación

Como dueño podés expulsar usuarios:

  • Del canal de voz - lo saca de la sala de voz actual.
  • Del servidor - le quita la membresía a la instancia.
